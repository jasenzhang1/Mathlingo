# Mathlingo — Web

The Mathlingo landing page: pick topics (linear algebra, calculus, probability
& statistics, ML foundations, DSA, quant finance) and choose a track —
refreshing forgotten skills as a working professional, or breaking into an
ML/data role through the bootcamp path.

React + TypeScript + Vite + Tailwind CSS v4.

## Develop

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```
